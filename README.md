# Godrex Capital website

A responsive, static HTML/CSS/JavaScript website concept for Godrex Capital. No build tools, framework runtime, backend, or package installation are needed.

## View the website

- Open `index.html` directly in a modern browser, or
- Serve this folder with the static-file server of your choice and visit its local address.

The standalone website files are `index.html`, `styles.css`, and `script.js`. They are separate from the existing Next.js starter project in `src/`; the Next.js development command runs that starter, not this standalone page.

## Included

- Responsive layouts for mobile, tablet, and desktop.
- Dark/light theme switch with a browser-local preference.
- Interactive market-category and platform tabs.
- Expandable FAQs, market education, glossary, and legal notices.
- A privacy notice describing the limited browser storage used by the theme and banner.
- Accessible navigation and reduced-motion styling.

## Important limitations

This is an informational frontend only. It does not provide brokerage or investment services, live market data, trade execution, account registration, authentication, 2FA, KYC document uploads, payments, administration, geoblocking, or customer support. UI previews do not create or represent real accounts or trades. Market values and spreads are deliberately left blank; no live or simulated prices are shown.

No license, regulator, company address, broker, partner, performance figure, award, or customer testimonial is claimed. Before representing a real financial service, obtain jurisdiction-specific legal advice and verify all regulatory authorizations, providers, operational safeguards, and disclosures. Do not collect sensitive personal or financial information through this static site.

## Production requirements

Before offering any financial service, this concept would need a compliant operating model, verified licensing and regional eligibility controls, a secure backend, validated market-data and broker integrations, compliant payment and KYC providers, reviewed legal disclosures, and tested privacy, security, and accessibility controls. Never expose private API credentials in browser code.
